# 苍祀（桌游可玩版）

《苍祀》是 2-6 人的中式部落德式桌游。本目录为 **GitHub Pages 部署包**：单个 `index.html` 自包含全部规则、界面与 AI，无任何构建步骤，上传即可玩。

## 玩法速览

- **行动阶段**：每轮每个玩家依次执行 1 次行动（采集工位 / 献祭 / 追祭 / 圣地立图腾 / 卡牌），也可跳过；全部跳过或工人用尽后进入下一轮。
- **终局**：回合制（默认 9 轮，5-15 可调）或固定分数（阈值 100-400 可调），可在设置中切换。
- **可选 DLC**（设置中开启）：
  - 职业：六职业，各具专属能力；
  - 上贡（官爵）：上贡高价值物资晋官爵，获得每轮物资 / 分数 / 专属官祀区特权；
  - 蛮族入侵（合作募军）：全体合作募军抵御蛮族，失败将扣分、损失物资、祭祀区封锁。

## 说明

- 单文件自包含：唯一外部依赖是字体 CDN（Noto Serif/Sans SC），无网络时页面仍可完整游玩（仅字体回退为系统字体）。
- 隐藏测试钩子：网址后加 `#auto` 自动开一局 AI 演示，加 `#autodlc` 自动开一局含全部 DLC 的演示。
- 移动端已适配，手机浏览器直接打开即可玩。
